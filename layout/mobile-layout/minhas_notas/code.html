Ponto de Enrolar e Temperagem

Módulo: Técnicas de Base • 12 min

Anotações Anteriores

schedule 02:45 do vídeo

A temperatura ideal para o brigadeiro atingir o ponto de enrolar é entre 92°C e 95°C. Se passar disso, a massa perde muita umidade e acaba cristalizando mais rápido. Importante notar o brilho acetinado que indica a emulsão correta da gordura.

Salvo em 12 de Out, 14:30 Técnicas de Base
schedule 08:12 do vídeo

Para enrolar e garantir a padronização: usar luvas de vinil levemente untadas com água ou manteiga sem sal. O peso ideal sugerido para eventos de luxo é de 18g para o doce + 3g para o confeito.
